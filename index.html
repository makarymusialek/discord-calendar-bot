Events Google Calendar Bot

A lightweight Discord bot for publishing Discord Scheduled Events to selected channels and providing one-click links for adding those events to Google Calendar.

Features

  • Publishes Discord Scheduled Events to a configured channel
  • Provides a one-click "Add to Google Calendar" button
  • Automatically updates posts when Discord events are edited
  • Handles cancelled or deleted events
  • Supports multiple Discord servers
  • Provides slash commands for configuration and synchronization
  • Does not require access to users' Google accounts

Google Calendar Integration

The bot does not use Google OAuth and does not access private Google Calendars. It only generates Google Calendar links containing information from Discord Scheduled Events.
